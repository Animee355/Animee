ANIMEE WEBSITE STARTER (DEMO)

Open index.html in a browser to preview.

Included:
- Your supplied Animee banner
- Dark anime-inspired theme
- Latest posts and history
- Demo admin studio to add a local photo/video or embed a public Facebook Reel/post URL
- Local browser storage and JSON post-list export/import

Important limitations:
- This is a front-end prototype, not a live hosted website.
- Local posts only exist in the same browser/device. Local video/photo files are not uploaded to a server.
- The admin panel is not protected by real authentication.
- It does not automatically read or publish to your Facebook Page.
- Live Facebook sync needs a hosted backend, Meta app, Page access token and approved permissions; never put a token in front-end code.
- A website cannot guarantee Facebook monetization eligibility. Only post content you have rights to use and follow Meta policies.
